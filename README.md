I studied computer engineering (MSc, graphics and multimedia track) and later did a master's in game design. My first job was on an indie team, where I shipped Martha Is Dead. Since then I've built 3D tools for architecture, digital twins of bridges and tunnels for the web, and training simulations in Unreal.

I enjoy digging into how engines and rendering pipelines work under the hood, and I like sharing what I learn along the way.

## Experience

- **Kairos3D** — 3D Software Engineer *(current)*: digital twin training simulations for the oil & gas industry in Unreal Engine 5.
- **Zuru Tech** — C++ Technical Artist: worked on [Dreamcatcher](https://zuru.tech/homes), a real-time architectural BIM platform.
- **Alten Italia** — 3D Developer: owned the web 3D library (Three.js / TypeScript) behind several digital twin applications for bridges and tunnels, including [ARGO](https://www.movyon.com/soluzione/infrastructure-management/argo/) by Movyon.
- **LKA** — Game Developer: optimization, materials and shaders on [**Martha Is Dead**](https://store.steampowered.com/app/515960/Martha_Is_Dead/) (PC, PlayStation, Xbox, 2022).
